# azoth-key-DIY

一个用于《宝可梦水银》的密钥定制工具。通过浏览器打开单个 HTML 文件，就可以创建或编辑精灵的 PMH1 密钥，再导入水银 Wiki 的 HOME。

当前版本为 **v1.2.2** · [更新说明](./CHANGELOG.md)

[下载 v1.2.2 HTML](./azoth-key-DIY-v1.2.2.html) · [v1.2.1](./azoth-key-DIY-v1.2.1.html) · [v1.2](./azoth-key-DIY-v1.2.html) · [v1.1](./azoth-key-DIY.html)

## 支持范围

- 水银 FC 1.33
- 水银对战塔特别版 3.0

工具内嵌了使用所需的资料和图片，打开后可以离线使用，无需安装、登录账号或连接服务器。

## 开始使用

1. 下载仓库中的 [azoth-key-DIY-v1.2.2.html](./azoth-key-DIY-v1.2.2.html)，用支持本地 HTML 的浏览器打开。
2. 选择精灵，并设置需要的属性、招式和初训家信息。
3. 点击**生成密钥**，复制生成的完整密钥。
4. 在水银 Wiki HOME 的“扫描二维码 / 输入密钥”入口粘贴密钥，导入后按 HOME 的流程保存存档。

手机页面提供当前精灵摘要和预览跳转，底部有生成、复制密钥的快捷按钮。支持系统文本分享的浏览器还可以直接分享密钥。

## 可以定制什么

- **基本信息**：种类、昵称、等级、性格、性别、闪光、特性、球种、携带物和亲密度。
- **个体值**：六项分别设置为 0～31，也可以一键设置 6V、0 攻或 0 速。
- **努力值**：每项 0～252，总和不超过 510。
- **招式**：四个槽位可分别按名称或编号搜索，设置招式和 PP 提升，也可以按等级填入招式。
- **初训家**：设置姓名和游戏中显示的 ID。

也可以读取受支持的已有 PMH1 密钥，继续编辑其中的精灵。

在“精灵”页可选择大师球、精灵球、豪华球、梦境球等 27 种球。**球种与携带物分别设置**，把球设为携带物不会改变球种。读取已有密钥会带回原球种，修改后需重新生成密钥。

## 修复旧版闪光密钥

v1.2.2 修复了部分密钥在 HOME 中显示为闪光、导入 FC 1.33 后被游戏判为普通个体的问题。使用新版读取原密钥，保持勾选“闪光精灵”，点击“生成密钥”，再将新密钥导入 HOME。读取这类密钥时，页面会显示修复提示，FC 导入结果按游戏实际规则展示。

修复会重新匹配个体识别值（PID），保留所选性格、性别、特性和其他设置。晃晃斑的斑纹可能随 PID 变化，页面会给出提示。

## 初训家信息

页面开放初训家姓名和显示 ID。新建精灵的隐藏 ID 为 0；读取已有密钥时，会保留原有隐藏 ID 及其他没有开放编辑的身份、来源信息。

修改显示 ID 时，工具会重新匹配个体识别值，以保持所选的性格、性别、闪光和特性。

## 版本转换预览

生成密钥后，可以选择 FC 1.33 或对战塔 3.0，查看目标版本下的等级、特性等结果和变化。

结果优先展示目标等级、特性和转换差异，其他字段可通过“查看完整设置”展开。

**切换目标版本只影响预览**，不会更改密钥，也不会自动调整经验或特性。

## 草稿与密钥保存

编辑内容会保存在当前浏览器中，刷新页面后可以恢复；恢复后需要重新生成密钥。如果浏览器无法保存草稿，页面会给出提示。

清除浏览器数据、更换浏览器或移动 HTML 文件，可能影响草稿的保存或读取。建议将需要长期保留的密钥复制或保存为文本。

## 使用须知

- 本工具不提供完整的合法性认证，不会检查所有招式习得方式和精灵获取途径。
- 部分官方 HOME 可以读取的精灵蛋密钥，由于特殊昵称编码，可能无法在本工具中读取。
- 刺尾虫的进化分支继续由游戏中的 PID 规则决定。修改晃晃斑的 PID 时，页面会提示斑纹可能变化。
- 已通过工作区保存的 HOME 副本验证密钥导入，并对两个版本的存档进行了内存写入与回读测试。**尚未验证真实手机操作、系统分享或模拟器内实际游玩。**
